# Sekar
PHP (singkatan dari PHP: Hypertext Preprocessor) adalah bahasa pemrograman scripting yang berjalan di sisi server (server-side). Bahasa ini dirancang khusus untuk membangun website yang dinamis dan interaktif. Sederhananya, PHP bekerja di belakang layar (backend) untuk mengolah data sebelum ditampilkan ke pengguna dalam bentuk halaman
